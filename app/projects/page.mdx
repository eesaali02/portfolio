## Enterprise Network Lab

<Meta>Hyper-V · Windows Server 2025 · VLANs · ServiceNow · Jira · Git</Meta>

A multi-VLAN enterprise home lab with IPAM, network diagrams and traffic policy, with every step documented in a public GitHub repository.

- Configured Windows Server 2025 RRAS for inter-VLAN routing and NAT, enforcing segmentation with filters and rules.
- Validated security policy with 8 documented tests (ping, port checks, nmap) from each network zone.
- Followed ITIL change management in ServiceNow, kept CMDB records for lab assets, and tracked work in Jira (10 Epics) and ProjectLibre.
